# BR-01: so khớp thư mục scan với mục lục + Duyệt Check scan (06/10)
Quyết định đã chốt: (1) Lệch mục lục -> chặn "Đạt" của Check scan; chỉ Admin được duyệt tiếp, BẮT BUỘC có lý do, lý do được lưu. (2) So khớp chạy TỰ ĐỘNG ngay khi gói scan xử lý xong, lưu vào gói, hiện ở hộp thoại Nộp S và ở Check scan. (3) Hộp chưa có mục lục: vẫn cho Duyệt, hiển thị "chưa có mục lục để so khớp".
Ngoài phạm vi: so số tờ/trang, mở từng file (phương án b), đổi tên theo QC-03.
Dữ liệu vào:
- Kỳ vọng = các dòng arrangement_dossiers của hộp (case_id) có missing_from_import_id IS NULL; khóa (dossier_number, dossier_suffix). Dòng có missing_from_import_id khác NULL = "không còn trong mục lục mới": KHÔNG phải kỳ vọng; thư mục trùng nó báo riêng (removed_from_catalog) và tính là lệch.
- Thực tế = đường dẫn tương đối (posix) các file PDF của gói (case_scan_files, is_pdf) tính từ thư mục hộp đã chọn. 1 thành phần (PDF ngay trong thư mục hộp) hoặc >= 3 thành phần (sâu quá cấp hồ sơ) -> misplaced_files. 2 thành phần = <thư mục hồ sơ>/<file>.
- Tên thư mục hồ sơ đọc bằng parse_dossier_number (0012 = 12, 12A = 12a); không đọc được -> invalid_folders. Hai thư mục ra cùng một hồ sơ -> duplicate_folders.
- File bìa (BIA.pdf hoặc tên chứa BIA, không phân biệt hoa thường) không là văn bản: thư mục chỉ có file bìa -> only_cover và hồ sơ đó tính là thiếu.
Kết quả: match_status = 'no_catalog' (hộp không có dòng mục lục nào, như catalog_dossier_count = 0) | 'matched' (mọi danh sách lỗi rỗng) | 'mismatch'. match_summary (JSON): catalog_total, folders_found, matched, missing, extra, invalid_folders, duplicate_folders, only_cover, removed_from_catalog, misplaced_files, truncated; mỗi danh sách tối đa 50 phần tử; nhãn hồ sơ dạng "12", "12a".
Chỉ tính khi gói 'done'. Gói 'failed' -> match_status NULL. Lỗi khi so khớp KHÔNG làm hỏng gói: match_status NULL + cờ catalog_match_error + ghi log.
Check scan (lát B2a), chỉ áp cho hành động Đạt (complete) của bước scan_qc, BR-04 giữ nguyên: nếu hộp không có mục lục -> cho qua. Ngược lại xét gói MỚI NHẤT (version lớn nhất): 'processing' -> 409 chờ xử lý xong; 'done' + 'matched' -> cho qua; 'done' + 'mismatch' hoặc match_status NULL, gói 'failed', hoặc chưa có gói nào -> chỉ Admin được qua và BẮT BUỘC reason không rỗng (lưu vào sự kiện chuyển bước, tối đa 500 ký tự); người không phải Admin hoặc thiếu lý do -> 409 {code: scan_catalog_mismatch | reason_required, message tiếng Việt}.
